1. Introducción

Objetivo

Presentar Asistencia WFM y el alcance de este manual.

Descripción

Asistencia WFM ayuda al supervisor a controlar el turno, cruzar PGPlanning con Avaya, registrar incidencias y preparar salidas operativas.

Captura pendiente

Vista general de la aplicación

Debe mostrar la pantalla principal con las zonas de trabajo y los accesos superiores.

Cómo utilizar la función

  1. Abre la aplicación.
  2. Revisa los accesos principales.
  3. Lee el flujo recomendado antes de comenzar el turno.

Resultado esperado

El supervisor identifica para qué sirve la herramienta y cómo se organiza el trabajo.

Consejos

💡 Consejo

Usa este manual como guía rápida durante el turno.

Errores frecuentes

⚠ Error frecuente
  • Empezar a registrar incidencias sin cargar datos actualizados.
  • Interpretar resultados sin comprobar la hora de consulta.

Observaciones

ℹ Observación

Las capturas definitivas se insertarán antes de la publicación final del PDF.

2. Primer uso

Objetivo

Arrancar el turno con la información compartida y los datos de asistencia actualizados.

Descripción

El primer uso debe seguir siempre el mismo orden para evitar conflictos y lecturas incompletas.

Captura pendiente

Pantalla principal

Debe mostrar PGPlanning, Avaya, botones de BBDD, CRUZAR DATOS y Panel del Turno.

Cómo utilizar la función

  1. Conecta la BBDD compartida o créala si es la primera vez.
  2. Actualiza BBDD.
  3. Pega el cuadrante PGPlanning.
  4. Pega los logados de Avaya.
  5. Pulsa CRUZAR DATOS.
  6. Revisa el Panel del Turno y gestiona incidencias.

Resultado esperado

La aplicación muestra estado del turno, ausencias, incidencias y salidas operativas.

Consejos

💡 Consejo

Actualiza la BBDD antes de registrar cualquier incidencia.

Errores frecuentes

⚠ Error frecuente
  • Cruzar datos sin Avaya actualizado.
  • No guardar BBDD tras modificar incidencias.

Observaciones

ℹ Observación

Este flujo es la base del uso diario.

3. Trabajo compartido (BBDD)

Objetivo

Permitir que varios supervisores compartan incidencias sin perder cambios.

Descripción

La BBDD compartida centraliza las incidencias y debe actualizarse al comenzar y guardarse al terminar.

Captura pendiente

Trabajo compartido BBDD

Debe mostrar Crear BBDD, Conectar BBDD, Actualizar BBDD, Guardar BBDD y estado de conexión.

Cómo utilizar la función

  1. Crea la BBDD si no existe.
  2. Conecta la BBDD compartida.
  3. Actualiza al comenzar.
  4. Registra o edita incidencias.
  5. Guarda al terminar.

Resultado esperado

Los cambios quedan disponibles para el resto de supervisores.

Consejos

💡 Consejo

Si hay conflicto, actualiza antes de continuar.

Errores frecuentes

⚠ Error frecuente
  • Trabajar sin BBDD conectada.
  • Modificar incidencias y no guardar.

Observaciones

ℹ Observación

La BBDD compartida es prioritaria en trabajo simultáneo.

4. Cruce de datos

Objetivo

Comparar planificación y presencia real.

Descripción

El cruce analiza PGPlanning y Avaya para clasificar la situación de cada empleado.

Captura pendiente

Cruce de datos

Debe mostrar las cajas de entrada y la tabla de resultados tras pulsar CRUZAR DATOS.

Cómo utilizar la función

  1. Pega PGPlanning completo.
  2. Pega Avaya actualizado.
  3. Comprueba la hora.
  4. Pulsa CRUZAR DATOS.
  5. Revisa estados y ausencias.

Resultado esperado

Cada empleado queda clasificado por turno, estado Avaya y situación actual.

Consejos

💡 Consejo

Repite el cruce tras registrar cambios importantes.

Errores frecuentes

⚠ Error frecuente
  • Usar datos incompletos.
  • Interpretar el resultado con hora incorrecta.

Observaciones

ℹ Observación

El cruce es la base del resto de salidas.

5. Panel del turno

Objetivo

Ofrecer una lectura rápida de cobertura, ausencias y acciones necesarias.

Descripción

El panel resume el estado operativo tras el cruce.

Captura pendiente

Panel del Turno

Debe mostrar tarjetas, contadores, avisos y acciones rápidas.

Cómo utilizar la función

  1. Cruza datos.
  2. Lee tarjetas y contadores.
  3. Revisa avisos.
  4. Abre incidencias si procede.
  5. Vuelve a cruzar tras cambios.

Resultado esperado

El supervisor identifica prioridades del turno.

Consejos

💡 Consejo

Consulta el panel antes de revisar detalle por empleado.

Errores frecuentes

⚠ Error frecuente
  • Tomar decisiones con datos antiguos.
  • Ignorar avisos de ausencia.

Observaciones

ℹ Observación

El panel depende del último cruce realizado.

6. Gestión de incidencias

Objetivo

Registrar, consultar y mantener ausencias e incidencias del turno.

Descripción

Las incidencias explican ausencias, situaciones futuras y cambios operativos.

Captura pendiente

Centro de incidencias

Debe mostrar formulario, filtros, agenda, incidencias activas y futuras.

Cómo utilizar la función

  1. Localiza la ausencia.
  2. Justifica una o varias ausencias.
  3. Indica tipo, fecha, horario y observaciones.
  4. Guarda la incidencia.
  5. Guarda la BBDD si trabajas compartido.

Resultado esperado

La incidencia queda disponible para panel, WhatsApp, Diario Operativo y Control Diario.

Consejos

💡 Consejo

Busca antes de crear una incidencia nueva.

Errores frecuentes

⚠ Error frecuente
  • Duplicar registros.
  • Dejar incidencias abiertas sin seguimiento.

Observaciones

ℹ Observación

El histórico permite revisar incidencias pasadas.

7. Plantilla de empleados

Objetivo

Mantener empleados y PIN correctamente identificados.

Descripción

La plantilla ayuda a mejorar el cruce y evita errores de identificación.

Captura pendiente

Plantilla de empleados

Debe mostrar formulario, buscador, sincronización y listado.

Cómo utilizar la función

  1. Abre Plantilla de empleados.
  2. Sincroniza CSV si procede.
  3. Busca por PIN o nombre.
  4. Edita datos necesarios.
  5. Guarda el empleado.

Resultado esperado

La aplicación reconoce empleados con mayor precisión.

Consejos

💡 Consejo

Revisa siempre el PIN antes que el nombre.

Errores frecuentes

⚠ Error frecuente
  • PIN incompleto.
  • Duplicar empleados.

Observaciones

ℹ Observación

La plantilla debe mantenerse actualizada.

8. Bandeja de franja

Objetivo

Revisar entradas, salidas y ausencias por franja.

Descripción

La bandeja ayuda a actuar sobre movimientos próximos o recientes.

Captura pendiente

Bandeja de franja

Debe mostrar entradas, salidas, ausencias y acciones inmediatas.

Cómo utilizar la función

  1. Cruza con la hora correcta.
  2. Abre Bandeja de franja.
  3. Revisa entradas y salidas.
  4. Actúa sobre pendientes.
  5. Registra incidencias si procede.

Resultado esperado

La franja queda revisada y con casos pendientes identificados.

Consejos

💡 Consejo

Úsala antes de cambios de hora importantes.

Errores frecuentes

⚠ Error frecuente
  • Consultar con hora incorrecta.
  • No actualizar Avaya.

Observaciones

ℹ Observación

La bandeja se basa en el último cruce.

9. WhatsApp

Objetivo

Preparar un resumen operativo para comunicación rápida.

Descripción

WhatsApp genera un texto listo para copiar y enviar.

Captura pendiente

Informe de WhatsApp

Debe mostrar el texto generado y el botón de copia.

Cómo utilizar la función

  1. Cruza datos actualizados.
  2. Revisa incidencias.
  3. Abre WhatsApp.
  4. Comprueba el texto.
  5. Copia al portapapeles.

Resultado esperado

Mensaje preparado con la situación del turno.

Consejos

💡 Consejo

Genéralo después de revisar ausencias.

Errores frecuentes

⚠ Error frecuente
  • Enviar texto antiguo.
  • No revisar incidencias antes de copiar.

Observaciones

ℹ Observación

El texto depende del estado actual de la aplicación.

10. Diario Operativo

Objetivo

Mostrar información estructurada para seguimiento del turno.

Descripción

El Diario Operativo recoge datos relevantes para consulta o traspaso.

Captura pendiente

Diario Operativo

Debe mostrar bloques de información y opción de descarga JSON.

Cómo utilizar la función

  1. Cruza datos actualizados.
  2. Registra incidencias relevantes.
  3. Abre Diario Operativo.
  4. Revisa la información.
  5. Descarga JSON si procede.

Resultado esperado

Información operativa ordenada y reutilizable.

Consejos

💡 Consejo

Genéralo tras las revisiones principales.

Errores frecuentes

⚠ Error frecuente
  • Abrirlo antes de registrar cambios.
  • Descargar una versión antigua.

Observaciones

ℹ Observación

No sustituye a la BBDD compartida.

11. Control Diario

Objetivo

Preparar datos para control posterior en LibreOffice Calc.

Descripción

Control Diario permite revisar y copiar salidas estructuradas.

Captura pendiente

Control Diario

Debe mostrar previsualización, copiar JSON, copiar tabla y análisis de plantilla.

  2. Abre Control Diario.
  3. Revisa previsualización.
  4. Copia JSON o tabla.
  5. Pega en LibreOffice Calc si procede.

Resultado esperado

Salida preparada para revisión o hoja de cálculo.

Consejos

💡 Consejo

Comprueba incidencias antes de copiar.

Errores frecuentes

⚠ Error frecuente
  • Copiar antes del último cruce.
  • Confundir JSON con tabla.

Observaciones

ℹ Observación

La salida debe revisarse antes de uso operativo.

12. Buenas prácticas

Objetivo

Reducir errores durante el uso diario.

Descripción

Las buenas prácticas ayudan a trabajar de forma consistente entre supervisores.

Captura pendiente

Flujo recomendado

Debe mostrar una secuencia visual de actualización, cruce, incidencias y guardado.

Cómo utilizar la función

  1. Actualiza BBDD al comenzar.
  2. Usa datos recientes.
  3. Registra incidencias importantes.
  4. Guarda BBDD tras cambios.
  5. Revisa salidas antes de comunicar.

Resultado esperado

Trabajo diario más estable y trazable.

Consejos

💡 Consejo

Ante duda, actualiza antes de modificar.

Errores frecuentes

⚠ Error frecuente
  • Trabajar con datos antiguos.
  • No guardar después de cambios.

Observaciones

ℹ Observación

Estas pautas deben seguirse especialmente en turnos compartidos.

13. Resolución de problemas

Objetivo

Resolver incidencias habituales de uso.

Descripción

Este capítulo resume comprobaciones rápidas cuando algo no cuadra.

Captura pendiente

Avisos y estados

Debe mostrar ejemplos de filtros, BBDD y estados de incidencia.

Cómo utilizar la función

  1. Comprueba conexión BBDD.
  2. Actualiza BBDD.
  3. Revisa filtros activos.
  4. Vuelve a cruzar datos.
  5. Comprueba hora de consulta.

Resultado esperado

El supervisor identifica la causa más probable del problema.

Consejos

💡 Consejo

Antes de crear incidencias nuevas, revisa si ya existen.

Errores frecuentes

⚠ Error frecuente
  • Confundir filtros con ausencia de datos.
  • Interpretar salidas desactualizadas.

Observaciones

ℹ Observación

Si persiste el problema, conserva los datos de entrada usados.

14. Preguntas frecuentes

Objetivo

Responder dudas habituales durante el turno.

Descripción

Preguntas rápidas para supervisores en uso diario.

Captura pendiente

Preguntas frecuentes

Debe mostrar una vista de ayuda o sección final del manual.

Cómo utilizar la función

  1. Busca la pregunta relacionada.
  2. Aplica la recomendación.
  3. Actualiza BBDD si trabajan varios supervisores.
  4. Guarda BBDD si has cambiado incidencias.

Resultado esperado

Dudas resueltas sin detener el flujo de trabajo.

Consejos

💡 Consejo

Si dos supervisores trabajan a la vez, ambos deben actualizar antes de modificar.

Errores frecuentes

⚠ Error frecuente
  • Olvidar guardar BBDD.
  • No revisar filtros cuando no aparecen incidencias.

Observaciones

ℹ Observación

Las respuestas se ampliarán con el uso real en producción.
